An extraordinary, highly interactive digital birthday story & surprise experience created for **Bhushan Bhusari** by his friends (**Manav, Viro, Sanvidhan, Samyak, and Vaibhav**).

## 🚀 How to Run in VS Code

1. Open folder in VS Code:
   `C:\Users\manav\OneDrive\Desktop\MY Creativity\Bhushan`

2. Open Terminal (`Ctrl + ~`) and run:
   ```bash
   npm.cmd install
   npm.cmd run dev
   ```

3. Open `http://localhost:3000/` in your browser.
4. Passkey: **`2005`**

## 📂 Features
- **Cinematic Loading Screen & Passcode Lock**: Password set to `2005` with hilarious hints on wrong entries.
- **Surprise Intro & Full-Screen Hero**: High-res beach portrait reveal & floating balloons.
- **Photo Gallery & Lightbox Carousel**: Displays real photos of Bhushan with 3D tilt polaroid cards and captions.
- **Video Archives ("THE EVIDENCE")**: Interactive reel player for real uploaded videos.
- **Meme Wall ("BHUSHAN LORE")**: Hilarious meme cards certified by friends.
- **Friends' Wishes & Signature Wall**: Dedicated cards for Manav, Viro, Sanvidhan, Samyak, and Vaibhav.
- **2005 to Now Timeline**: Milestone scrolling timeline using real photos.
- **Interactive Birthday Cake**: Multi-tier SVG cake with candles lighting & blow-out interaction.
- **Canvas Fireworks & Birthday Blast**: Colorful rockets, confetti explosion, and celebratory sound effects.
- **Emotional Finale**: Closing letter & replay button.
